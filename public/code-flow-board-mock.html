How this removes the confusion. The flow strip is the only place commits move between branches, so there's no stray “PR branch” button and no way to end up on the wrong branch. dev/… lives only in the dev worktree, pr/… only in the PR worktree — collisions and detached HEAD are impossible. Clicking the pr/… chip jumps to that PR on the My/Active PRs tab; the PR tabs stay exactly as they are.
